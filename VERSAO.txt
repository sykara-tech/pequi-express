Correção crítica: "entrava sozinho" após Sair

Causa: sessões GO ID e Pequi eram independentes. Sair em um não
encerrava o outro, então pequi_session ou goid_session restava ativa.

Agora:
  - Sair no GO ID limpa: goid_session + goid_sso + pequi_session + flag logout
  - Sair no Pequi limpa: pequi_session + goid_sso + goid_session + flag logout
  - Qualquer restauração (F5, abrir site de novo) respeita a flag até novo login
  - Flag só some no login/SSO bem-sucedido

IMPORTANTE após atualizar:
  1) Substitua TODOS os arquivos do site pela pasta deste zip
  2) Abra o site → F12 → Application → Local Storage → Clear
  3) Ou use janela anônima na primeira vez
  4) Faça login de novo e teste o Sair
